# NSE Swing AI Pro

A Streamlit research dashboard for NSE swing-trading analysis.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Included
- 100-point model architecture
- Technical, momentum and basic fundamental scoring
- Daily top-3 scanner
- Entry / stop / targets / R:R
- Risk-based position sizing
- SQLite trade journal
- CSV export
- AI review prompt
- Backtest research page

## Important
This is decision-support software, not investment advice and not a guaranteed-profit system.
The included data adapter uses Yahoo Finance for demonstration. For production use, replace it with properly licensed market, financial, corporate-action and news data.
